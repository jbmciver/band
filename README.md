# Wollongong Salvo Band app

Installable web app for band members (iPhone and Android): what we're playing, who's away, and updating your own availability.

- `index.html` is generated by the band page builder in the Bandmaster Hub (`band.app.html`). Don't edit it by hand.
- Roster data is not stored here. The app fetches it live from the band's Google Apps Script (`?api=data`), and sends availability updates through it (`?api=send`). The band password is checked by the script and remembered on each phone.
